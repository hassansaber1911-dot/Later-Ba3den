# Later | بعدين — Phase 1.7

Corrected Later vs History logic.

- Later = only things still to do: Pending + In Progress.
- History = everything ever added: Pending, In Progress, Done, Not Interested, and Archived.
- Later filters: All / Pending / In Progress.
- History keeps all status filters.
- Done and Not Interested automatically disappear from Later but remain in History.
- Mobile-first UI and optional images retained.
