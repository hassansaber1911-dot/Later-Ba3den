# Later | بعدين

**Later | بعدين** is a functional product prototype for capturing the things we keep saying we'll do later.

Movies to watch, books to read, people to contact, places to visit, things to buy, courses to take, and work follow-ups — all in one place.

## 💡 Product Idea

The core journey is:

**Capture → Come Back → Take Action → Keep the History**

Items are organized into:

🎬 Watch · 📚 Read · 💬 Connect · 💼 Work · 🛍️ Buy · 🎓 Learn · 📍 Visit

Only **Title** and **Category** are required. Dates, times, notes, and images are optional.

## ✨ Key Features

- Quick item capture
- Pending & In Progress tracking
- Optional dates, notes, and images
- Done & Not Interested actions
- Archive & Restore
- Full History with status filters
- Mobile-first responsive UI

## 🧠 Product Logic

**Later** = things you still want to do  
**History** = everything you've added

This keeps the active list simple without losing previous activity.
